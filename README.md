I estimate Division 9 (flooring) work for a commercial general contractor. I started in takeoff and estimating, not software — I build the tools because I know exactly what the department needs them to do, and no one was going to build it for me.

### Building

- **[OpenTakeoff](https://github.com/Kentucky-ai/opentakeoff)** — open-source (Apache-2.0) PDF takeoff and estimating software. Agents-first: one-click room detection, materials and quantities, an MCP server included, not bolted on.
- **Kentucky AI** — applied-research shop for AI-native construction tooling. [kentucky-ai.com](https://kentucky-ai.com)
- **Spline** — the estimating platform OpenTakeoff grew out of. Closed-source, running on real supplier pricing and production data.
- A patent-pending takeoff and estimating model, trained on real project closeout data rather than a synthetic demo.
